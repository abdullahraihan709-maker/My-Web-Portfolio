Overview

Dev Stack helps software engineers explore, compare and assemble their preferred technology stack.

It covers frontend, backend, database and DevOps tools. Pick technologies from the library and your custom stack updates in real time, with duplicates blocked and a toast confirming every change.

What it does

  • Interactive stack builder. Add or remove tools with real-time state tracking, and get toast notifications for additions, removals and duplicate attempts.
  • Badges and metadata. Tools are labelled by difficulty and rating, with colour-coded badges for quick recognition.
  • One-variable theming. A single CSS gradient variable drives the global theme, so the look stays consistent everywhere.
  • Mobile-first layout. The interface is designed for small screens first and scales up to desktop.

Challenges along the way

  • Handling duplicates gracefully

    Adding a technology that is already in your stack shouldn't fail silently or create a copy. The builder blocks the duplicate and explains why with a toast.

  • Loading data the React 19 way

    Technology data is read from local JSON with React's use() hook inside a Suspense boundary, which meant rethinking where loading and fallback states live compared with the usual useEffect approach.

  • One gradient, whole theme

    The global look is driven by a single CSS gradient variable, so changing one value re-themes buttons, headings and badges consistently.
